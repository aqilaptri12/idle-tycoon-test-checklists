# Checklist: Prestige System

**Feature:** Reset progress for permanent bonuses.

## ✅ Core Checks
- [ ] Prestige button appears after requirements are met
- [ ] Confirmation popup appears before reset
- [ ] Resources and buildings reset to initial state
- [ ] Prestige bonus is added permanently
- [ ] UI displays total bonus correctly

## 🐛 Edge Cases
- [ ] Cancelling the confirmation popup does not lose progress
- [ ] Prestige is not possible while offline
- [ ] Repeated prestige stacks bonuses correctly
