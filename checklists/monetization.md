# Checklist: Monetization / IAP

**Feature:** In-App Purchases & shop.

## ✅ Core Checks
- [ ] Shop displays all items with correct prices
- [ ] Prices match local currency
- [ ] Successful purchase → item is delivered
- [ ] Failed purchase → no resources are lost
- [ ] Restore purchase works

## 🐛 Edge Cases
- [ ] Double-tapping buy → no double charge
- [ ] Buying while offline → clear error message
- [ ] Cancelling mid-transaction → no item delivered
