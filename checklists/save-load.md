# Checklist: Save / Load

## ✅ Core Checks
- [ ] Progress is saved automatically
- [ ] Force close app → reopen → progress is the same
- [ ] Logging into account → progress syncs
- [ ] Switching devices → progress follows

## 🐛 Edge Cases
- [ ] Uninstall → reinstall → progress is lost (expected)
- [ ] Saving while offline → no error
- [ ] Loading a save from an older version → no crash
