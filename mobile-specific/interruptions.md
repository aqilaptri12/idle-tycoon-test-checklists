# Checklist: Mobile Interruptions

## ✅ Core Checks
- [ ] Incoming call → game pauses
- [ ] After call → game resumes normally
- [ ] SMS/WhatsApp notification → game does not pause
- [ ] Alarm → game pauses
- [ ] Low battery popup → game continues running

## 🐛 Edge Cases
- [ ] Incoming call during ad → ad continues playing
- [ ] Incoming call during loading → no crash
