# Checklist: Network Issues

## ✅ Core Checks
- [ ] Turn off Wi-Fi → "No Connection" message appears
- [ ] Turn on Wi-Fi → game auto-reconnects
- [ ] Airplane mode → game can still idle
- [ ] Slow connection → no crash

## 🐛 Edge Cases
- [ ] Disconnect during IAP → transaction is safe
- [ ] Disconnect during save → data is not corrupted
